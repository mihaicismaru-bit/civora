# VÂLCEA CLAR — S1 Edition Delivery Engine

S1 is the small deterministic layer between an approved editorial edition and the existing site/social publishers.

It does **not** rewrite articles and does **not** call platform APIs. Existing channel adapters remain the only components that publish. S1 records exactly what version of each article was selected for which channel and reconciles provider/site evidence back into one durable ledger.

## Files

- `edition_delivery.py` — builds and reconciles the ledger.
- `manifest.json` — current edition, article payload versions, canonical URLs and selected destinations.
- `queue.json` — durable delivery records keyed by `edition + article + content_version + channel`. Old records are retained.
- `report.json` — current edition counts, confirmations and explicit leftovers/blockers.

The JSON files are generated by the S1 workflow and are intentionally committed so a failed or restarted workflow cannot silently forget a delivery.

## Invariants

1. A confirmation is monotonic: a later incomplete adapter state cannot erase a previously confirmed delivery.
2. A provider snapshot can prove only one article content version. A correction creates a new delivery record and remains pending until a fresh provider/site snapshot appears.
3. A selected delivery remains present until it is confirmed, explicitly blocked/cancelled, or superseded by a new version; records are never dropped merely because a later outbox no longer selects them.
4. `ready`/`outbox_ready` means **pending delivery**, never “published”. `hold`/`blocked` is preserved as an explicit blocker.
5. Site and social delivery are reconciled from the same edition manifest and article payload version.

## Run

```bash
python valcea-clar/delivery/edition_delivery.py --self-test
python valcea-clar/delivery/edition_delivery.py
```

The workflow `.github/workflows/valcea-clar-edition-delivery.yml` reruns reconciliation when the current edition, public site route manifest, social outboxes, or social confirmation states change.
