# EUCONS Commercial OS

EUCONS is the autonomous commercial website and commercial operating system for Euroconsult.

## Product objective

Convert verified expertise and EU-funding intelligence into trust, qualified leads, matched opportunities, proposals, and measurable commercial outcomes.

## Runtime doctrine

- GitHub is the source of truth for code, content contracts, state, receipts, QA and automation.
- EUCONS is a separate CIVORA vertical and must remain independently buildable and deployable.
- No WordPress and no ChatGPT Sites runtime dependency.
- GitHub Pages is the autonomous preview/staging target; production hosting is intentionally provider-independent until final handoff.
- PARTENER.EU provides verified funding intelligence through an explicit read-only projection contract; EUCONS does not mutate PARTENER canonical facts.
- Public claims, case results, prices and funding facts fail closed when evidence is missing or contradictory.

## Development state

Canonical state: `ops/checkpoint.json`.

Target terminal state: `PRODUCTION_READY`, followed only by external credential/domain handoff and production smoke validation.
