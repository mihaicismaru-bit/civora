# PARTENER.EU — Civic Intelligence Brand Baseline v1

Status: IMPLEMENTED CANDIDATE
Research decision: P/Bridge + Civic Forest + Source Sans 3 / Source Serif 4.

## Identity principles
1. Credibil, clar, competent, independent, actual.
2. Instrument de decizie verificabil, nu „site care vinde fonduri”.
3. Navy = structură/autoritate; emerald = brand/action/verification accent.
4. Semantic status colors are independent from brand identity and always paired with text.
5. No EU-star circle, euro sign, handshake, lightbulb, leaf, puzzle or generic funding iconography.
6. P/Bridge is intentionally geometric and abstract to avoid suggesting official EU/MIPE affiliation.

## Master assets
- brand-mark-v1.svg — compact P/Bridge mark; favicon/app-icon source.
- brand-horizontal-v1.svg — horizontal reference lock-up.
- brand-civic-intelligence-v1.css — semantic design tokens and brand overrides.

## Typography
UI/data: Source Sans 3.
Editorial/page headings: Source Serif 4.
Fallbacks remain system-safe. Numeric finance/date values use tabular numerals.

- Visible 3px focus ring.

- Reduced motion honored.
